# Database Systems II. - PL/SQL Practice (Pokémon Edition)

Welcome to the course! This semester, we will maintain and develop the Kanto region database and its corresponding Python (FastAPI) backend.

📚 **Course Info:** [https://io.uni-eszterhazy.hu/downloadCourseInfo/101966](https://io.uni-eszterhazy.hu/downloadCourseInfo/101966)

## 🛠️ Prerequisites

1. [Git](https://git-scm.com/downloads)
2. [Docker Desktop](https://www.docker.com/products/docker-desktop/)
3. [Visual Studio Code](https://code.visualstudio.com/)
4. **Dev Containers** Microsoft extension in VS Code

## 📝 Workflow for Assignments

Every student must start their work in the following way:
- Clone the branch to your local machine.
- Create your own branch based on your Neptun code.
- The task descriptions are located in the `exercises/tasks.MD` file.
- Implementations must be done in the appropriate Python files (e.g., in the `app/` folder) and SQL files.
- Continuously check your code using the `make test` command!

> ❕**Important** - Do not try to push to the main or feature/pokedex-python-api branches under any circumstances. Create a folder with your Neptun code on the `finals` branch.
